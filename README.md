# Malineni Lakshmaiah Women's Engineering College Website

## 📌 Project Description

A modern, responsive college website developed for **Malineni Lakshmaiah Women's Engineering College** using **HTML, CSS, and JavaScript**. The complete website is designed in a **single HTML file**.

## ✨ Main Features

* 🏫 College introduction and About section
* 🎓 Engineering departments
* 🏢 Campus facilities
* 📊 College statistics with animated counters
* 📝 Admission enquiry form
* 📅 Campus events
* 💬 Student testimonials
* 📞 Contact form and college details
* 📱 Responsive design for mobile, tablet, and desktop
* ✨ Smooth animations and interactive navigation

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive features and animations

## 📁 Project Structure

```text
MLWEC-Website/
├── index.html
└── README.md
```

## 🚀 How to Run

1. Download or clone the project.
2. Open `index.html` in a web browser.
3. The website will run directly without any additional installation.

## 🎯 Purpose

The website provides students, parents, and visitors with an attractive and easy-to-use platform to explore the college, courses, facilities, admissions, events, and contact information.
